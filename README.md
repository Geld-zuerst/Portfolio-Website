## 🎯 Why I Built This

I wanted my portfolio to be more than a static page listing skills.

The goal was to create a space that reflects how I approach development:

> **Learn something → build something → experiment → improve → repeat.**

Instead of trying to make everything perfect from the beginning, I prefer building, testing ideas, learning from the process, and continuously improving what I've created.
